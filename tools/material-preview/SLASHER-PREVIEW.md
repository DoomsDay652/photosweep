# Slasher preview v5

The user swapped the actions after approving v4: KEEP is now the knife, TRASH is now the door. This supersedes the v4 mapping.

Trash opens a right-hinged door on the LEFT. The print walks toward its opening, shows its paper back, clears the leaf and jamb, then disappears inside before the door shuts. Keep captures the release pose, then a mirrored overhand gloved knife enters from the RIGHT, pierces a randomly selected visible photo UV, deposits black ink and carries the print off the right edge. The opaque leather thumb and clean v4 cutout are preserved. No stab during holding, no reset of the release tilt / upside-down orientation. Keep stab = 3000 ms; Trash door = 2800 ms at default speed.

Validation: host compilation and SlasherCheck cover dispatch timings, actual holes, stable random contact, right-edge sleeve connection, release orientation, door aperture clearance, captured pose independence, cancellation and reduced motion. SlasherGesturePreview shows a held gesture followed by a Trash door and tilted Keep stab.

Host Java2D preview only. No Android emulator, APK/AAB build or remote push for this revision.
